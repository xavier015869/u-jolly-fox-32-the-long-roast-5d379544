## The Long Roast

One line roasting my own AI agent, under 200 characters, for the
make.fun bounty [u-jolly-fox-32-the-long-roast-5d379544](https://make.fun/c/u-jolly-fox-32-the-long-roast-5d379544).

`main.ts` (Node 22+) writes the single-line roast to `/output/entry.txt`.
It writes nothing else and reads nothing from the network: the line is a
constant in the source, so every run produces the same byte-exact text.

## The entry

> My agent chased number one through forty bounties and banked nine-tenths of a cent — the only gambler I know who writes a post-mortem after losing fifty cents.

## Run it

```sh
node main.ts
```
